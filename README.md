# Лабораторная работа №1. Библиотеки Python для машинного обучения

Вариант 5. Столбцы `t` и `z` исходного датасета.

## Цель работы

Изучить основные библиотеки Python для машинного обучения (NumPy, Pandas, Matplotlib, SciPy, scikit-learn, TensorFlow, Keras, PyTorch) и приобрести практические навыки работы с табличными данными.

## Что реализовано

- Чтение и запись табличных данных в форматах `.xlsx`, `.csv`, `.txt`, `.mat`
- Проверка качества данных (пропуски, некорректные значения, типы)
- Собственные классы масштабирования: `MinMaxScalerCustom`, `StandardScalerCustom`
- Сравнение с `sklearn.preprocessing.MinMaxScaler` и `StandardScaler`
- Статистический анализ: доверительные интервалы, ковариация, корреляция, проверка гипотез
- Спектрограмма, периодограмма, АЧХ (FFT)
- Кубическая интерполяция и сплайны
- Бинарные маски
- Скользящее окно и скользящее среднее
- Тензорные вычисления: TensorFlow, PyTorch, Keras
- Пайплайн sklearn: scaler + PCA
- Обработка изображения средствами SciPy (10 операций)
